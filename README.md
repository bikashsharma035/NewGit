# NewGit – My DevOps Learning Project

## Project Overview

Welcome to my GitHub repository!

This repository is created to practice Git, GitHub, DevOps, CI/CD pipelines, and DevSecOps security concepts.

## Project Objectives

- Learn Git and GitHub version control.
- Practice commits, branches, and pull requests.
- Understand GitHub Actions and CI/CD automation.
- Learn DevSecOps security best practices.
- Explore GitHub security scanning tools.

## DevSecOps Security Practices

In this project, I will learn how to:

1. Enable Dependabot security alerts.
2. Identify vulnerable dependencies.
3. Configure GitHub secret scanning.
4. Understand CodeQL code scanning.
5. Secure CI/CD pipelines.
6. Avoid committing passwords and API keys.

## Tools and Technologies

- Git and GitHub
- GitHub Actions
- Dependabot
- CodeQL
- Docker
- DevSecOps

## Learning Outcome

By completing this project, I aim to understand how software developers securely manage source code, automate workflows, identify vulnerabilities, and improve application security.
